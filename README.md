# Sonder Coffee — Responsive Landing Page

A responsive coffee-brand landing page built using HTML5 and CSS3 only.

## Files
- `index.html` — semantic page structure
- `style.css` — Flexbox, CSS Grid, typography and responsive layouts
- `assets/images/` — folder for local image assets

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Test these viewport widths
- Desktop: 1440px
- Tablet: 900px and 768px
- Mobile: 390px and 360px

## CSS concepts demonstrated
- Flexbox: header, hero actions, intro strip, contact section and footer links
- CSS Grid: hero, product cards, story split, values and footer
- Media queries: tablet, mobile and small-phone layouts
- Accessibility: semantic landmarks, descriptive image alt text and keyboard focus styles

## Images
The starter uses remote Unsplash image URLs. For a self-contained submission, download suitable images into `assets/images/` and replace the image `src` values with relative paths.
